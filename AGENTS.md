# Teo Services — Project Rules

## Stack
- Next.js 16+ App Router
- React (server components by default)
- Tailwind CSS 4+ (utility-first, custom config)
- Deploy: Vercel

## Design System
- Theme: Dark glassmorphism
- Accent: #00d4ff (cyan electric)
- Fonts: Outfit (headings) + Plus Jakarta Sans (body)
- No Inter, Roboto, Arial, system fonts
- Glass cards: backdrop-blur + rgba borders + layered colored shadows
- Animations: staggered reveals, scroll fade-in, hover lifts

## Code Style
- TypeScript strict
- Components in src/components/sections/ and src/components/ui/
- Mobile-first responsive
- Semantic HTML
- No unnecessary dependencies
- No inline styles — Tailwind only

## Content
- All text in Romanian
- Conversational tone, not corporate
- Focus on client results, not technology
